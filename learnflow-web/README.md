# LearnFlow - 隨身學習筆記與知識庫工作台

LearnFlow 是一個專為自學者打造的「大字體、極簡直覺、開箱即用」隨身學習筆記與知識庫系統。

## ✨ 核心特色
1. **📚 原始資料庫 (Materials Vault)**：集中管理學習講義、官方教材，支援本地上傳 `.md`、`.txt`、`.docx` 與 `.pdf`。
2. **📖 高清原版 PDF 畫布閱讀器**：以 PDF.js Canvas 完整還原原版排版、色彩與數學公式，支援連續閱讀、左右雙頁對開與原生全螢幕沉浸模式。
3. **📝 我的筆記本 (Personal Notebook)**：提供邊學邊記的卡片空間，支援與教材建立關聯。
4. **🤖 AI 知識伴讀與整合檢索**：自動搜尋關聯教材與筆記，提供解答與測驗練習，支援一鍵將 AI 總結存入筆記。
5. **⚡ 100% 純靜態零伺服器**：採用純前端架構（HTML5 + Tailwind CSS CDN + Vanilla JS），開箱即用，專為 GitHub Pages 設計。

## 🚀 部署方式
直接將此資料夾下的所有內容上傳至 GitHub 倉庫的 `main` 分支根目錄，並在倉庫設定（Settings ➔ Pages）中將 Source 設為 `Deploy from a branch` (Branch: `main`, Folder: `/ (root)`) 即可上線！
